# Shopora Landing Page

A modern React + Tailwind CSS landing page for Shopora, built to support local business discovery.

## Setup

1. Install dependencies:
   ```bash
   cd shopora-landing
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Notes

- Uses React, Vite, Tailwind CSS, and Framer Motion.
- Includes modern hero, features, process, pricing, testimonials, FAQ, and newsletter sections.
- Designed with a premium SaaS aesthetic and local business focus.
